Инструкция по загрузке ваших фотографий:

Поместите в эту папку (public/images/) ваши фотографии с следующими названиями:

1. hero.jpg   — Фоновое фото для главного экрана (Hero)
2. story1.jpg — Фото для «Главы первой» (Хроника чувств)
3. story2.jpg — Фото для «Главы второй» (Хроника чувств)

Поддерживаемые форматы: .jpg, .png, .webp
